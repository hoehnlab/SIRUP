Most studies have more than one tissue section. You may have several sections from one donor, bulk AIRR-seq of the same tissue, or blood from other time points. If you call clones on all of them together, one clone ID means the same lineage in every sample. You can then ask where a clone was seen.

One SIRUP object can hold all of this:

  • spatial can be a named list of Seurat objects, one per section.
  • The receptor table holds the rows from every section and every bulk sample. A sample column tells SIRUP which section each row belongs to.
  • Rows whose sample does not name a section stay in the table as nonspatial rows. SIRUP does not put them on a tissue, but clone calling, trees, and your own summaries can use them.

This vignette follows Figure 5 of the SIRUP paper. The MG thymus data come from a patient who had a thymectomy. Besides the two Visium sections, there is bulk BCR-seq of the thymus, and of blood taken at the thymectomy and 12 months later. We ask which eGC clones also appear in the blood.

Set up

library(SIRUP)
library(dplyr)
library(ggplot2)
extdata <- system.file("extdata", package = "SIRUP")

spatial <- list(
  mg_thymus_slice1 = readRDS(file.path(extdata, "mg_thymus_slice1_spatial.rds")),
  mg_thymus_slice2 = readRDS(file.path(extdata, "mg_thymus_slice2_spatial.rds"))
)

read_bcrs <- function(file, sample, compartment) {
  airr::read_rearrangement(file.path(extdata, file)) |>
    mutate(sample = sample, compartment = compartment)
}

sections <- bind_rows(
  read_bcrs("mg_thymus_slice1_bcr.tsv.gz", "mg_thymus_slice1", "thymus_slice1"),
  read_bcrs("mg_thymus_slice2_bcr.tsv.gz", "mg_thymus_slice2", "thymus_slice2")
) |>
  extractSpatialIds(
    id = "sequence_id",
    spatial_id = "barcode_10x",
    regex = ",([ACGT]{16})$",
    suffix = "-1"
  )

bulk <- bind_rows(
  read_bcrs("mg_thymus_bulk_thymus_1.tsv.gz", "bulk_thymus_1", "bulk_thymus"),
  read_bcrs("mg_thymus_bulk_thymus_2.tsv.gz", "bulk_thymus_2", "bulk_thymus"),
  read_bcrs("mg_thymus_bulk_blood_month0_1.tsv.gz", "bulk_blood_month0_1", "blood_month0"),
  read_bcrs("mg_thymus_bulk_blood_month0_2.tsv.gz", "bulk_blood_month0_2", "blood_month0"),
  read_bcrs("mg_thymus_bulk_blood_month12_1.tsv.gz", "bulk_blood_month12_1", "blood_month12"),
  read_bcrs("mg_thymus_bulk_blood_month12_2.tsv.gz", "bulk_blood_month12_2", "blood_month12")
)

bcrs <- bind_rows(sections, bulk) |>

    min_j_length = 30,
    min_junction_length = 10,
    productive_only = TRUE,

read_bcrs() reads one AIRR file and adds two columns: sample and compartment. After the barcodes come out of the section IDs, the code makes each sequence_id unique and tree-safe. It puts the sample name in front, because IDs repeat between files, and it replaces the comma with _, because dowser renames tree tips that contain a comma. The spatial rows get a sample that matches the names of the spatial list. The bulk and blood rows have their own sample names and no barcode.

To keep the package small, the bulk files hold a subset of the bulk data: the blood sequences of clones seen in a section, and up to 10 bulk thymus sequences of each clone that reaches the blood.

Create a multi-sample object

Give createSIRUP() the named list and the sample column:

sirup <- createSIRUP(
  spatial = spatial,
  receptors = bcrs,

  sample = "sample",
  image_scale = "lowres",

Visium barcodes repeat between sections: AAACAAGTATCTCCCA-1 exists in both. SIRUP matches each receptor to a spot by the pair of sample and barcode, so the two sections never mix.

If the sections need different image settings, give named values: image_scale = c(mg_thymus_slice1 = "hires", mg_thymus_slice2 = "lowres").

Where was each clone seen?

Each row has a compartment. For each clone, count its sequences in each compartment, and record the eGCs that hold it:

clones <- getReceptors(sirup) |>
  group_by(clone_id) |>
  summarise(
    in_section = any(compartment %in% c("thymus_slice1", "thymus_slice2")),
    n_egc = sum(!is.na(polygon_id)),
    egcs = paste(sort(unique(na.omit(polygon_id))), collapse = ", "),
    n_bulk_thymus = sum(compartment == "bulk_thymus"),
    n_blood_month0 = sum(compartment == "blood_month0"),
    n_blood_month12 = sum(compartment == "blood_month12")
  ) |>
  mutate(
    in_egc = n_egc > 0,
    in_blood = n_blood_month0 + n_blood_month12 > 0
  )

count(clones, in_egc, in_blood)

When the tips of a clone fall in more than one section, it has one element per clone and section instead, named <clone>::<sample>, and each one pairs the full tree with the map of one section. Each element also holds a legend for the tip shapes and colors. Show the section that holds the eGC tips:
