Spatial Clonal Dominance

This vignette shows how to draw spatial regions, calculate clone dominance inside those regions, and make region-level plots for clone IDs and V-gene annotations.

Clone dominance is the fraction of BCR rows inside a polygon assigned to each clone. spatialCloneDominance() also returns the BCR rows and spatial coordinates inside each polygon, so the same object can be passed directly to the plotting functions.

By default, this page shows runnable code but does not evaluate it. To render plots from the full local thymus dataset, render on the cluster with SIRAP_RENDER_PLOTS=true.

Select Polygon Regions

selectSpatialPolygons() opens a Shiny app for selecting polygon vertices over the spatial tissue coordinates. Each click snaps to the nearest full-resolution spatial barcode, even if downsample_n is used to make the browser plot lighter.

For an HPC interactive node, define the host and port explicitly. Start the R session on the interactive node, run the code below, then tunnel the port from your laptop. For example:

ssh -N -L 8788:t01.hpcc.dartmouth.edu:8788 f007p0j@discovery.dartmouth.edu

Then open http://127.0.0.1:8788 in your laptop browser. Use host = "0.0.0.0" when Shiny is running on the compute node and the browser connection arrives through the login node tunnel.

Calculate Clonal Dominance

For this example, the denominator is the whole heavy-chain BCR pool inside each polygon. exclude_singletons = TRUE removes clone IDs represented by only one BCR row before calculating dominance.

dominanceBcrs <- bcrClones %>%
  mutate(
    spaced_clone_id = paste0("heavy_", clone_id),
    chain_for_pairing = "heavy"
  )

clonalDominance <- spatialCloneDominance(
  bcrs = dominanceBcrs,
  object = thymus,
  polygon = allGcsPolygons,
  barcode_col = "barcode_8um",
  clone_col = "spaced_clone_id",
  locus_col = "chain_for_pairing",
  locus = "heavy"
)

clonalDominanceNoSingletons <- spatialCloneDominance(
  bcrs = dominanceBcrs,
  object = thymus,
  polygon = allGcsPolygons,
  barcode_col = "barcode_8um",
  clone_col = "spaced_clone_id",
  locus_col = "chain_for_pairing",
  locus = "heavy",
  exclude_singletons = TRUE
)

head(clonalDominance$dominance)

The returned object contains:

  • dominance: clone counts and proportions for each polygon.
  • region_barcodes: spatial barcodes inside each polygon.
  • region_coordinates: spatial coordinate rows inside each polygon.
  • region_bcrs: BCR rows inside each polygon, with plotting coordinates and V-gene summaries.
  • polygons: polygon vertices prepared for plotting.

dominance includes allele-level v_gene, allele-stripped v_gene_family, and broad v_gene_superfamily values for each clone.

Plot Regional BCRs

plotSpatialRegionBCRs() plots the BCR rows inside the selected polygons over the tissue image. top_n keeps the most common displayed levels and groups lower-frequency levels as Other.

  clonalDominance,
  object = thymus,
  color_by = "clone_id",

  point_size = 0.5,

Plot Pie Summaries

plotSpatialPolygonPies() makes pie summaries from the dominance object. With mode = "side_by_side", the tissue image and numbered polygons appear on the left and the pie charts appear on the right. The top levels are identified within each polygon, then unioned across polygons so a clone that is top-ranked in any polygon remains named everywhere it appears. Other levels are grouped as Other.

clonePies <- plotSpatialPolygonPies(
  clonalDominance,
  object = thymus,
  fill_by = "clone_id",
  mode = "side_by_side",
  top_n = 10,
  label_top_n = 5,
  polygon_alpha = 0.2
)
ggsave(
  filename = file.path(dominanceOutDir, sprintf("%s_all_gcs_heavy_clone_id_pies.pdf", sampleLower)),
  plot = clonePies,

The spatially clipped pie mode fills each polygon with the pie slices. This requires the suggested sf package. Labels are usually best left off for this mode; use spatial_legend = TRUE for variables with a manageable number of levels, such as V-gene superfamily.

if (requireNamespace("sf", quietly = TRUE)) {
  cloneSpatialPies <- plotSpatialPolygonPies(
    clonalDominance,
    object = thymus,
    fill_by = "clone_id",
    mode = "spatial_clipped",
    top_n = 10,
    label_top_n = 0,
    pie_alpha = 0.9
  )
  ggsave(
    filename = file.path(dominanceOutDir, sprintf("%s_all_gcs_heavy_clone_id_spatial_pies.pdf", sampleLower)),
