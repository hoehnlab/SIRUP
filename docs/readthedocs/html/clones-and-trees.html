A clone is a group of B or T cells that descend from one ancestor cell and share its receptor rearrangement. In germinal centers, B cell clones gain somatic hypermutations. A lineage tree of a B cell clone shows how its sequences relate to each other. Spatial AIRR-seq lets you put each tip of that tree on the tissue.

SIRUP does not reimplement clone calling or tree building. It runs the Immcantation tools (scoper, dowser, shazam) on the receptor table inside the SIRUP object. It then adds the spatial part: clone maps, trees paired with tissue plots, and distances between tips in and between regions.

This vignette uses MG thymus section 2 and its eGC polygons. You need the Immcantation packages to run it:

install.packages(c("scoper", "dowser", "shazam", "alakazam", "cowplot"))
BiocManager::install("ggtree")

Set up

library(SIRUP)
library(dplyr)
library(ggplot2)
extdata <- system.file("extdata", package = "SIRUP")

thymus <- readRDS(file.path(extdata, "mg_thymus_slice2_spatial.rds"))
bcrs <- airr::read_rearrangement(file.path(extdata, "mg_thymus_slice2_bcr.tsv.gz")) |>
  extractSpatialIds(
    id = "sequence_id",
    spatial_id = "barcode_10x",
    regex = ",([ACGT]{16})$",
    suffix = "-1"
  ) |>
  mutate(sequence_id = gsub(",", "_", sequence_id)) |>
  filterAirr(
    locus_val = "IGH",
    min_v_length = 250,
    min_j_length = 30,
    min_junction_length = 10,
    productive_only = TRUE,
    min_consensus_count = NULL,
    spatial_id = "barcode_10x"
  ) |>
  filter(!grepl("[^ACGT]", junction))
#> filterAirr kept 2195 of 3801 rows (dropped 1606).

sirup <- createSIRUP(
  spatial = thymus,
  receptors = bcrs,
  spatial_id = "barcode_10x",
  image_scale = "lowres",
  swap_coords = FALSE,
  polygons_path = file.path(extdata, "mg_thymus_slice2_gc_polygons.csv")
)

The setup also replaces the comma in each sequence_id with _. dowser writes trees in Newick format, where a comma separates tips, so it renames tips that contain one. With the comma gone, the tip names match the receptor table, and SIRUP can find each tip on the tissue.

Call clones inside the object

The setup made a SIRUP object without clones. To call clones, run scoper::hierarchicalClones() through updateReceptors(). updateReceptors() gives the receptor table to the function as its first argument, with your other arguments. It then stores the returned table and validates the object:

sirup <- updateReceptors(
  sirup,
  scoper::hierarchicalClones,
  threshold = 0.1,
  summarize_clones = FALSE,
  nproc = 1
)

sirup

hierarchicalClones() groups sequences with the same V gene, J gene, and junction length whose junctions differ by less than threshold. The SIRUP paper used threshold = 0.1 for BCRs. TCRs do not mutate, so call TCR clones with scoper::identicalClones().

The function writes a clone_id column, and updateReceptors() records it as the clone field. If a function writes a different column, record it yourself with receptor_fields = list(clone = "my_clone_column").

Germlines

A lineage tree starts at the germline sequence of its clone. dowser::createGermlines() reconstructs one germline per clone from the IMGT reference sequences. The SIRUP paper made the germlines and removed likely PCR chimeras in the object.

SIRUP does not include the IMGT references. Download them (for example with the Immcantation script fetch_imgtdb.sh) and set SIRUP_IMGT_DIR to the folder that holds the human V, D, and J FASTA files, such as ~/share/germlines/imgt/human/vdj. The germline and tree chunks below run only when that folder exists.

references <- dowser::readIMGT(imgt_dir)
#> [1] "Read in 1198 from 17 fasta files"

sirup <- updateReceptors(
  sirup,
  dowser::createGermlines,
  references = references,
  id = "sequence_id",
  nproc = 1
)

sirup <- updateReceptors(sirup, function(receptors) {
  chimera <- shazam::slideWindowDb(
    receptors,
    sequenceColumn = "sequence_alignment",
    germlineColumn = "germline_alignment_d_mask",
    mutThresh = 6,
    windowSize = 10
  )
  receptors[!chimera, ]
})

Somatic hypermutation

shazam::observedMutations() counts the mutations of each sequence against a germline. With clonal germlines, use germline_alignment_d_mask. Here we use germline_alignment, the germline of each sequence that IgBLAST wrote, so the chunk runs without the IMGT references. The result goes in mu_freq, the fraction of mutated positions:

sirup <- updateReceptors(
  sirup,
  shazam::observedMutations,
  sequenceColumn = "sequence_alignment",
  germlineColumn = "germline_alignment",
  frequency = TRUE,
  combine = TRUE
)
summary(getReceptors(sirup)$mu_freq)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#> 0.00000 0.01462 0.03750 0.04184 0.06377 0.13467

plotReceptors() can color spots by a numeric receptor column in place of groups. Give the column to value. When a spot has several receptors, value_combine sets how SIRUP combines them (the mean, by default):

plotReceptors(
  sirup,
  group = "locus",
  value = "mu_freq",
  value_colors = c("white", "darkred"),
  receptor_size = 1.3,
  polygons = TRUE,
  polygon_alpha = 0,
  polygon_color = "black",
  title = "Mean SHM frequency per spot"
)

Choose clones

Trees are most useful for expanded clones. Here we choose clones in the eGCs of this section that have between 10 and 60 sequences:

clone_sizes <- getReceptors(sirup) |>
  group_by(clone_id) |>
  summarise(
    n_sequences = n(),
    n_in_gc = sum(!is.na(polygon_id)),
    n_gcs = n_distinct(na.omit(polygon_id)),
    gcs = paste(sort(unique(na.omit(polygon_id))), collapse = ", ")
  ) |>
  filter(n_sequences >= 10, n_sequences <= 60, n_in_gc > 0) |>
  arrange(desc(n_in_gc))

Build trees

Two functions run dowser on the object:

  • formatSpatialClones() runs dowser::formatClones() and stores the result as an analysis.
  • getSpatialTrees() runs dowser::getTrees() on a stored formatted-clone analysis and stores the trees as another analysis.

Both take the dowser arguments. Tree building takes time for large clones, so first make a smaller object with only the clones you want. updateReceptors() with dplyr::filter() does this:

tree_sirup <- updateReceptors(sirup, dplyr::filter, clone_id %in% tree_clones)

tree_sirup <- formatSpatialClones(
  tree_sirup,
  analysis_name = "formatted_clones",
  id = "sequence_id",
  germ = "germline_alignment_d_mask",
  traits = c("barcode_10x", "polygon_id")
)

tree_sirup <- getSpatialTrees(
  tree_sirup,
  f_clones_analysis = "formatted_clones",
  analysis_name = "trees",
  build = "pratchet"
)

trees <- getAnalysis(tree_sirup, "trees")
trees
#> # A tibble: 3 × 5
#>   clone_id data       locus  seqs trees  
#>   <chr>    <list>     <chr> <int> <list> 
#> 1 196      <airrClon> IGH      38 <phylo>
#> 2 739      <airrClon> IGH      15 <phylo>
#> 3 810      <airrClon> IGH      13 <phylo>

traits keeps the columns that the tree plots need. Keep the spatial ID, so SIRUP can put each tip on the tissue, and any column that you want to color by.

build = "pratchet" builds maximum parsimony trees, which is fast. For the paper we used maximum likelihood (build = "pml"). For B cell specific models, use IgPhyML (build = "igphyml" with the igphyml path).

Store the trees in the main object:

sirup <- setAnalysis(sirup, "trees", trees)

Pair each tree with the tissue

plotSpatialCloneTreePairs() makes two plots for each clone: the lineage tree and a tissue map. Each tip gets one color in both plots, so you can find a tip of the tree on the tissue:

pairs <- plotSpatialCloneTreePairs(
  trees,
  object = sirup,
  clone_val = tree_clones,
  id = "sequence_id",
  zoom = TRUE,
  polygons = TRUE,
  polygon_alpha = 0,
  polygon_color = "black"
)
names(pairs)
#> [1] "196" "739" "810"

cowplot::plot_grid(
  pairs[[1]]$tree,
  pairs[[1]]$spatial_clone,
  rel_widths = c(1.2, 1)
)

The result is a list with one element per clone. Each element holds a tree plot and a spatial_clone plot. Tips with a spot in this section are circles. Tips without one, such as bulk sequences, are squares and appear in the tree only. Sequences in the same spot share a point on the map.

Color tips by group

When a clone has many tips, one color per tip is hard to read. clusterTreesTips() cuts each tree into k connected groups of related tips. Here k = 4 for every tree:

clustered <- clusterTreesTips(
  trees,
  k = 4,
  id = "sequence_id",
  cluster = "tree_cluster"
)

cluster_pairs <- plotSpatialCloneTreePairs(
  clustered,
  object = sirup,
  clone_val = tree_clones,
  id = "sequence_id",
  color_by = "tree_cluster",
  zoom = TRUE,
  polygons = TRUE,
  polygon_alpha = 0,
  polygon_color = "black",
  show_spatial_legend = TRUE
)

cowplot::plot_grid(
  cluster_pairs[[1]]$tree,
  cluster_pairs[[1]]$spatial_clone,
  rel_widths = c(1.2, 1)
)

With k = "auto", the function chooses k for each tree from k_range. It stops when one more cut reduces the mean within-group patristic distance by less than improvement_threshold (10% by default). A tree with little structure can get k = 1, which gives all its tips one color.

color_by accepts any column of the dowser clone data. For example, color_by = "polygon_id" colors each tip by its eGC, because we kept polygon_id in traits.

Save every pair

spatialCloneTreePairsToPDF() writes one page per clone:

spatialCloneTreePairsToPDF(cluster_pairs, "tree_pairs.pdf", width = 12, height = 6)

Tree distance and physical distance

Do sequences in the same eGC have shorter tree distances than sequences in different eGCs? The patristic distance between two tips is the sum of the branch lengths between them. tipPatristicMatrix() gives these distances for a set of tips. Here we take the selected clone in the most eGCs, and compare its tip pairs in the same eGC with its pairs in different eGCs:

multi_gc_clone <- clone_sizes |>
  filter(clone_id %in% tree_clones) |>
  slice_max(n_gcs, n = 1, with_ties = FALSE) |>
  pull(clone_id)
multi_gc_clone
#> [1] "739"

index <- which(trees$clone_id == multi_gc_clone)
clone_data <- trees$data[[index]]@data
tree <- trees$trees[[index]]

gc_tips <- clone_data |>
  filter(!is.na(polygon_id), sequence_id %in% tree$tip.label) |>
  select(sequence_id, polygon_id)

distances <- tipPatristicMatrix(tree, gc_tips$sequence_id)

pairs_table <- as.data.frame(as.table(distances)) |>
  rename(tip_a = Var1, tip_b = Var2, distance = Freq) |>
  filter(as.character(tip_a) < as.character(tip_b)) |>
  mutate(
    gc_a = gc_tips$polygon_id[match(tip_a, gc_tips$sequence_id)],
    gc_b = gc_tips$polygon_id[match(tip_b, gc_tips$sequence_id)],
    pair = if_else(gc_a == gc_b, "same eGC", "different eGCs")
  )

pairs_table |>
  group_by(pair) |>
  summarise(n_pairs = n(), median_distance = median(distance))
#> # A tibble: 2 × 3
#>   pair           n_pairs median_distance
#>   <chr>            <int>           <dbl>
#> 1 different eGCs       5          0.0273
#> 2 same eGC            10          0.0150

In this clone, tips in the same eGC are closer in the tree than tips in different eGCs. One clone is not enough for a conclusion, because tip pairs share branches. In the SIRUP paper we ran this comparison over all GC clones, with a mixed model and a random effect for each clone.

With collapse = TRUE (the default), formatClones() merges identical sequences into one tip, so not every sequence keeps its own tip.
