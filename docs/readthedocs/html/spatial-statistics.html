A map can suggest that a gene clusters, or that a clone stays in one place. A spatial statistic tells you whether the pattern is stronger than chance. SIRUP has five tests. Each one answers a different question:

Question Function Statistic
Does one variable cluster in space? spatialMoran() Global Moran’s I
Where are the clusters? spatialLocalMoran() Local Moran’s I
Do two variables have the same spatial pattern? spatialLee() Lee’s L
Are spots of type A near spots of type B? spatialRipleyCrossK() Ripley’s cross K
Do the spots of one clone sit next to each other? spatialCloneJoinCount() Join count

spatialCloneSpread() also measures how far each clone spreads across a section.

The tests use the spdep and spatstat packages. Each one accepts a SIRUP object and reads the spot coordinates and image settings from it. The examples use MG thymus section 2.

read_receptors() reads a consensus table, takes the spot barcode from sequence_id, and keeps the high-quality sequences of one locus with unambiguous junctions. BCR clones come from scoper::hierarchicalClones(). TCRs do not mutate, so TCR clones come from scoper::identicalClones().

Neighbors

Most of these statistics compare each spot with its neighbors. You choose the neighbors in one of two ways:

  • k: the k nearest spots. Use k = 6 for standard Visium, where each spot has six neighbors on a hexagonal grid. Use k = 8 for Visium HD, where each bin has eight neighbors on a square grid. Larger values of k measure patterns over larger distances.
  • radius: all spots within a distance. SIRUP measures distances in image pixels at the stored image_scale, so the same radius in micrometers needs a different number at "lowres" and at "hires".

k does not depend on the image scale, so it is the safer default.

Global Moran’s I

Moran’s I measures spatial autocorrelation: whether neighboring spots have similar values.

\[ I = \frac{N}{W} \frac{\sum_i \sum_j w_{ij}(x_i - \bar{x})(x_j - \bar{x})}{\sum_i (x_i - \bar{x})^2} \]

Here \(x_i\) is the value at spot \(i\), \(w_{ij}\) is 1 if spot \(j\) is a neighbor of spot \(i\) and 0 if not, \(N\) is the number of spots, and \(W\) is the sum of all \(w_{ij}\). \(I\) near 0 means no spatial pattern. Positive \(I\) means that similar values cluster. Negative \(I\) means that they alternate, as on a chessboard.

variable_type tells SIRUP what variable is:

  • "feature": a gene, from the assay and layer you give.
  • "metadata": a numeric spot metadata column. For a text column, give value to test the spots that have that value.
  • "receptor": 1 for spots with any receptor and 0 for other spots. variable is only a label here.
  • "clone": 1 for spots with the clone that variable names.
aicda <- spatialMoran(
  bcr_sirup,
  variable = "AICDA",
  variable_type = "feature",
  assay = "Spatial",
  layer = "data",
  k = 6
)

Local Moran’s I

Global Moran’s I gives one number for the whole section. Local Moran’s I (also called LISA) gives one value for each spot. A spot with a high positive value has a high (or low) value itself and neighbors with similar values. Its z-score shows how far it is from the value expected by chance.

gc_b_local <- spatialLocalMoran(
  bcr_sirup,
  variable = "GC B",
  variable_type = "metadata",
  k = 6
)
head(gc_b_local[, c("cell", "value", "local_i", "z_i", "p_value")])

  bcr_sirup,
  gc_b_local,
  point_size = 1,

The clusters of high GC B cell proportion sit where we drew the eGC polygons. Each spot has its own p value, so correct for multiple testing (for example with p.adjust(method = "BH")) before you call a spot significant.

Lee’s L: two variables

Lee’s L combines Pearson correlation with spatial smoothing. It is high when two variables are high in the same neighborhoods, even if they do not peak in the same spots.

In MG, patients make antibodies against the acetylcholine receptor (AChR). CHRNA1 codes for the AChR α subunit. Thymic myoid cells express it. Lee’s L tests whether CHRNA1 and the GC marker AICDA share a spatial pattern in this section. MS4A1 (CD20) gives a positive control, because GC B cells express both MS4A1 and AICDA:

lee_control <- spatialLee(
  bcr_sirup,
  x = "AICDA", y = "MS4A1",
  assay = "Spatial", layer = "data", k = 6
)
lee_chrna1 <- spatialLee(
  bcr_sirup,
  x = "AICDA", y = "CHRNA1",
  assay = "Spatial", layer = "data", k = 6
)

tibble(
  pair = c("AICDA and MS4A1", "AICDA and CHRNA1"),
  L = c(lee_control$L, lee_chrna1$L),
  p = c(lee_control$test$p.value, lee_chrna1$test$p.value)
)
#> # A tibble: 2 × 3
#>   pair                    L        p
#>   <chr>               <dbl>    <dbl>
#> 1 AICDA and MS4A1   0.0975  2.17e-49
#> 2 AICDA and CHRNA1 -0.00171 5.66e- 1

The control pair shares a pattern. AICDA and CHRNA1 do not: in this section, \(L\) is near zero and the test is not significant.

The analytical test (method = "analytical") builds a dense matrix with one entry for each pair of spots. That is fine for Visium. For Visium HD, use method = "mc", which uses permutations and sparse weights.

Ripley’s cross K: are A spots near B spots?

Ripley’s cross K counts, for each distance \(r\), how many type B points are within \(r\) of an average type A point:

\[ K_{AB}(r) = \frac{|W|}{N_A N_B} \sum_{i \in A} \sum_{j \in B} \mathbf{1}(d_{ij} \le r) \]

\(|W|\) is the area of the tissue window and \(d_{ij}\) is the distance between points \(i\) and \(j\). SIRUP compares the observed curve with curves from random relabeling of the points. If the observed curve is above the envelope of the random curves, A and B are closer than chance.

T follicular helper (Tfh) cells give B cells the signals that keep a germinal center going. Here we ask whether spots with GC B cells sit near spots with Tfh cells. First, label each spot from its cell2location proportions. updateSpatial() runs a function on the Seurat object and stores the result:

bcr_sirup <- updateSpatial(bcr_sirup, function(spatial) {
  gc_b <- spatial$`GC B` > 0.10
  tfh <- spatial$Tfh > 0.10
  spatial$gc_tfh_mark <- case_when(
    gc_b & !tfh ~ "GC B",
    tfh & !gc_b ~ "Tfh",
    TRUE ~ NA_character_
  )
  spatial
})

table(getSpatial(bcr_sirup)$gc_tfh_mark, useNA = "ifany")
#> 
#> GC B  Tfh <NA> 
#>   76  211 2916

Spots with neither cell type, or with both, get NA, and the test leaves them out. Then run the test. nsim sets the number of random relabelings. Use 99 or more for a final analysis:

gc_tfh_k <- spatialRipleyCrossK(
  bcr_sirup,
  mark_col = "gc_tfh_mark",
  i = "GC B",
  j = "Tfh",
  nsim = 39,
  max_r = 40
)

plotRipleyCrossK(gc_tfh_k, title = "Cross K: GC B spots to Tfh spots")

The distance \(r\) is in image pixels at the stored image_scale. To convert it to micrometers, use the Visium spot size. A spot is 55 µm wide, and the image object stores its diameter in full-resolution pixels:

scale_factors <- getSpatial(bcr_sirup)@images[[1]]@scale.factors
um_per_pixel <- 55 / (scale_factors$spot * scale_factors$lowres)
um_per_pixel
#> [1] 11.7135
max(gc_tfh_k$plot_data$r) * um_per_pixel
#> [1] 468.5401

So max_r = 40 lowres pixels is about 470 µm.

In this section the observed curve is below the envelope at every distance. Random relabeling keeps the marked spots where they are and shuffles the labels. A curve below the envelope therefore means that GC B spots sit next to other GC B spots, and Tfh spots next to other Tfh spots, more often than next to each other. The two cell types form separate groups at the 10% threshold. The rule that drops spots with both cell types adds to the separation. Change the thresholds or the marks to ask a different question.

Join counts: does a clone stay together?

The join-count test is the natural test for a clone. Take every spot with a BCR. Mark the spots that have the clone. Count the neighbor pairs in which both spots have the clone (the “joins”). If the clone stays in one place, there are more joins than random labeling gives.

spatialCloneJoinCount() runs spdep::joincount.test() for each clone in at least min_spatial_ids spots. When the object has stored polygons, the function runs one test per polygon by default. Set use_stored_polygons = FALSE for one test over the whole section:

big_clones <- getReceptors(bcr_sirup) |>
  filter(!is.na(barcode_10x)) |>
  distinct(clone_id, barcode_10x) |>
  count(clone_id, sort = TRUE) |>
  slice_head(n = 5) |>
  pull(clone_id)

join_count <- spatialCloneJoinCount(
  bcr_sirup,
  clone_val = big_clones,
  use_stored_polygons = FALSE,
  k = 6,
  return_data = TRUE
)

spatialCloneSpread() describes how far each clone reaches across the section, from the pairwise distances between its sequences:

Keep the results

Store results that you want to keep in the object, so they travel with the data:

bcr_sirup <- bcr_sirup |>
  setAnalysis("moran_aicda", aicda) |>
  setAnalysis("local_moran_gc_b", gc_b_local) |>
  setAnalysis("lee_aicda_chrna1", lee_chrna1) |>
  setAnalysis("clone_join_count", join_count) |>
  setAnalysis("clone_spread", spread)
